## 二、同步原语速查

| 原语 | 核心用途 | 典型场景 |
|---|---|---|
| `synchronized + wait/notify` | 互斥 + 等待/唤醒 | 基础方案，面试问底层 |
| `ReentrantLock + Condition` | 精确唤醒指定线程 | 多线程轮转（比 notifyAll 精准） |
| `Semaphore` | 控制并发数 / 交替 / 限流 | 交替打印、H2O 配比 |
| `CountDownLatch` | 一次性等待 N 个线程就绪 | 按序打印的「依赖等待」 |
| `CyclicBarrier` | 循环屏障，N 线程到齐后一起走 | H2O、多轮轮转 |
| `AtomicInteger + CAS 自旋` | 无锁方案 | 高性能场景、避免上下文切换 |
| `volatile` | 保证可见性 + 禁止重排 | 状态标志位 |

2. **1117、1195**（屏障 + 多线程轮转）

## 四、各题解法骨架（一题多解）

### 1114 按序打印 Print in Order

要求：三个线程分别打印 first / second / third，必须按序。

**方案 A：CountDownLatch（依赖等待）**

```java
class Foo {
    private CountDownLatch second = new CountDownLatch(1);
    private CountDownLatch third = new CountDownLatch(1);

    public void first(Runnable printFirst) {
        printFirst.run();
        second.countDown();
    }
    public void second(Runnable printSecond) {
        try { second.await(); } catch (InterruptedException e) {}
        printSecond.run();
        third.countDown();
    }
    public void third(Runnable printThird) {
        try { third.await(); } catch (InterruptedException e) {}
        printThird.run();
    }
}
```

**方案 B：Semaphore（信号量）**

```java
class Foo {
    private Semaphore s2 = new Semaphore(0);
    private Semaphore s3 = new Semaphore(0);

    public void first(Runnable printFirst) {
        printFirst.run();
        s2.release();
    }
    public void second(Runnable printSecond) {
        try { s2.acquire(); } catch (InterruptedException e) {}
        printSecond.run();
        s3.release();
    }
    public void third(Runnable printThird) {
        try { s3.acquire(); } catch (InterruptedException e) {}
        printThird.run();
    }
}
```

**方案 C：volatile 自旋（无锁）**

```java
class Foo {
    private volatile int flag = 1;

    public void first(Runnable printFirst) {
        printFirst.run();
        flag = 2;
    }
    public void second(Runnable printSecond) {
        while (flag != 2) { /* 自旋 */ }
        printSecond.run();
        flag = 3;
    }
    public void third(Runnable printThird) {
        while (flag != 3) { /* 自旋 */ }
        printThird.run();
    }
}
```

### 1115 交替打印 FooBar

要求：两个线程交替打印 foo / bar，共 n 次。

**方案 A：Semaphore（互斥交替）**

```java
class FooBar {
    private int n;
    private Semaphore foo = new Semaphore(1);
    private Semaphore bar = new Semaphore(0);

    public FooBar(int n) { this.n = n; }

    public void foo(Runnable printFoo) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            foo.acquire();
            printFoo.run();
            bar.release();
        }
    }
    public void bar(Runnable printBar) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            bar.acquire();
            printBar.run();
            foo.release();
        }
    }
}
```

**方案 B：synchronized + wait/notify**

```java
class FooBar {
    private int n;
    private boolean fooTurn = true;

    public FooBar(int n) { this.n = n; }

    public synchronized void foo(Runnable printFoo) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            while (!fooTurn) wait();
            printFoo.run();
            fooTurn = false;
            notifyAll();
        }
    }
    public synchronized void bar(Runnable printBar) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            while (fooTurn) wait();
            printBar.run();
            fooTurn = true;
            notifyAll();
        }
    }
}
```

> ⚠️ 面试高频追问：为什么用 `while` 而不是 `if`？（防虚假唤醒 spurious wakeup）

### 1116 打印零与奇偶数 Zero Even Odd

要求：线程 zero 打印 0，线程 even 打印偶数，线程 odd 打印奇数，输出形如 `0102030405...`。

**方案：Semaphore 三信号量轮转**

```java
class ZeroEvenOdd {
    private int n;
    private Semaphore zero = new Semaphore(1);
    private Semaphore even = new Semaphore(0);
    private Semaphore odd = new Semaphore(0);

    public ZeroEvenOdd(int n) { this.n = n; }

    public void zero(IntConsumer printNumber) throws InterruptedException {
        for (int i = 1; i <= n; i++) {
            zero.acquire();
            printNumber.accept(0);
            if (i % 2 == 0) even.release();
            else odd.release();
        }
    }
    public void even(IntConsumer printNumber) throws InterruptedException {
        for (int i = 2; i <= n; i += 2) {
            even.acquire();
            printNumber.accept(i);
            zero.release();
        }
    }
    public void odd(IntConsumer printNumber) throws InterruptedException {
        for (int i = 1; i <= n; i += 2) {
            odd.acquire();
            printNumber.accept(i);
            zero.release();
        }
    }
}
```

### 1117 H2O 生成 Building H2O

要求：每 2 个 H + 1 个 O 组合成一个水分子，多个线程任意调用，必须按 2:1 配比输出。

**方案 A：CyclicBarrier（循环屏障，3 个线程到齐放行）**

```java
class H2O {
    private CyclicBarrier barrier = new CyclicBarrier(3);
    private Semaphore h = new Semaphore(2);
    private Semaphore o = new Semaphore(1);

    public void hydrogen(Runnable releaseHydrogen) throws InterruptedException {
        h.acquire();
        try { barrier.await(); } catch (BrokenBarrierException e) {}
        releaseHydrogen.run();
        h.release();
    }
    public void oxygen(Runnable releaseOxygen) throws InterruptedException {
        o.acquire();
        try { barrier.await(); } catch (BrokenBarrierException e) {}
        releaseOxygen.run();
        o.release();
    }
}
```

**方案 B：synchronized 计数**

```java
class H2O {
    private int hCount = 0;
    private int oCount = 0;

    public synchronized void hydrogen(Runnable releaseHydrogen) throws InterruptedException {
        while (hCount == 2) wait();
        releaseHydrogen.run();
        hCount++;
        if (hCount == 2 && oCount == 1) { hCount = 0; oCount = 0; }
        notifyAll();
    }
    public synchronized void oxygen(Runnable releaseOxygen) throws InterruptedException {
        while (oCount == 1) wait();
        releaseOxygen.run();
        oCount++;
        if (hCount == 2 && oCount == 1) { hCount = 0; oCount = 0; }
        notifyAll();
    }
}
```

### 1195 交替打印字符串 FizzBuzz

要求：4 个线程分别处理「能被3整除」「能被5整除」「能被15整除」「其他」，从 1 到 n 按序输出。

**方案：ReentrantLock + 4 个 Condition（精确唤醒）**

```java
class FizzBuzz {
    private int n;
    private int i = 1;
    private ReentrantLock lock = new ReentrantLock();
    private Condition fizz = lock.newCondition();
    private Condition buzz = lock.newCondition();
    private Condition fizzbuzz = lock.newCondition();
    private Condition number = lock.newCondition();

    public FizzBuzz(int n) { this.n = n; }

    private void next() {
        i++;
        // 根据下一个 i 的整除性唤醒对应线程
        if (i > n) {
            fizz.signalAll(); buzz.signalAll(); fizzbuzz.signalAll(); number.signalAll();
        } else if (i % 15 == 0) fizzbuzz.signal();
        else if (i % 3 == 0) fizz.signal();
        else if (i % 5 == 0) buzz.signal();
        else number.signal();
    }

    public void fizz(Runnable printFizz) throws InterruptedException {
        lock.lock();
        try {
            while (i <= n) {
                if (i % 3 == 0 && i % 5 != 0) { printFizz.run(); next(); }
                else fizz.await();
            }
        } finally { lock.unlock(); }
    }
    // buzz / fizzbuzz / number 同理，按整除性判断
}
```

### 1226 哲学家进餐 Dining Philosophers

要求：5 个哲学家围坐，左右各一把叉子，避免死锁。

**方案：限制「最多 4 人同时拿叉」**

```java
class DiningPhilosophers {
    private Semaphore[] forks = new Semaphore[5];
    private Semaphore limit = new Semaphore(4); // 关键：最多 4 人同时就餐，破环

    public DiningPhilosophers() {
        for (int i = 0; i < 5; i++) forks[i] = new Semaphore(1);
    }

    public void wantsToEat(int philosopher,
                           Runnable pickLeftFork,
                           Runnable pickRightFork,
                           Runnable eat,
                           Runnable putLeftFork,
                           Runnable putRightFork) throws InterruptedException {
        limit.acquire();
        int left = philosopher;
        int right = (philosopher + 1) % 5;
        forks[left].acquire();
        forks[right].acquire();
        pickLeftFork.run();
        pickRightFork.run();
        eat.run();
        putLeftFork.run();
        putRightFork.run();
        forks[left].release();
        forks[right].release();
        limit.release();
    }
}
```

> 死锁的三种破法：①限制同时就餐人数（如上，≤4）；②按固定顺序拿叉（小号先拿）；③奇数/偶数哲学家拿叉顺序相反。面试爱追问「为什么这样能避免死锁」。
