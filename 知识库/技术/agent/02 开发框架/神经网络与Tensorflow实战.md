## 一、神经网络底层原理

### 1. 什么是神经网络

- 由大量"神经元"按层连接组成的计算模型：**输入层 → 隐藏层（可多层）→ 输出层**
- 每个神经元做两件事：**线性加权**（z = Wx + b）+ **非线性激活**（a = f(z)）
- 本质：用可学习的权重矩阵逼近任意复杂函数（万能逼近定理）

### 2. 正向传播（Forward Propagation）

- 数据从输入层逐层向前计算，直到输出层得到预测值
- 每层输出作为下一层输入：`a⁽ˡ⁾ = f(W⁽ˡ⁾ · a⁽ˡ⁻¹⁾ + b⁽ˡ⁾)`

### 3. 损失函数（Loss Function）

- 衡量预测值与真实值的差距，是模型优化的目标
- 回归任务常用 **MSE（均方误差）**；分类任务常用**交叉熵（Cross Entropy）**

### 4. 反向传播（Backpropagation）

- 利用**链式法则**，从输出层向输入层逐层计算每个参数对损失的梯度
- 解决的核心问题："哪个参数该为误差负责、负多少责"

### 5. 梯度下降（Gradient Descent）

- 沿梯度反方向更新参数：`θ = θ - lr × ∇Loss`
- **学习率 lr** 是关键超参数：太大震荡不收敛，太小训练慢
- 常见优化器变体：SGD → Momentum → **Adam**（实战默认首选）

### 6. 激活函数

| 函数 | 特点 | 适用场景 |
|------|------|----------|
| **Sigmoid** | 输出压缩到 (0,1)；深层网络易梯度消失 | 二分类输出层 |
| **Tanh** | 输出 (-1,1)，零中心化 | 早期隐藏层，现已少用 |
| **ReLU** | 计算快、有效缓解梯度消失 | 现代隐藏层默认选择 |

## 二、TensorFlow 实战：波士顿房价预测

课程 Case 使用波士顿房价数据集（`housing.csv`），通过三种实现路径对比讲解，代码位于课程 `code/` 目录：

| 实现路径 | 文件 | 说明 |
|----------|------|------|
| **NumPy 手动实现** | `numpy_forward.py` / `numpy_model.py` / `numpy_boston.py` | 不依赖框架，手写正向传播与训练流程，用于理解底层原理 |
| **TensorFlow/Keras** | `tensorflow_boston.py` | `model.fit()` 一行完成训练循环；训练产物保存为 `boston_model.keras` |
| **PyTorch 对照** | `pytorch_boston.py` | 同一任务的 PyTorch 实现，对比两个框架的 API 风格 |
| **TF 数据并行** | `tensorflow_boston_dataparallel.py` | 数据并行训练示例 |

**工程要点：**

- **数据标准化**：训练前对特征归一化，`scaler.pkl` 保存归一化器——预测时必须使用同一个 scaler，否则结果失真
- **模型加载与推理**：`load_predict.py` 演示加载已训练模型做预测
- **激活函数对比示例**：`code/activation_function/`（sigmoid / tanh / relu 三个独立小例子）

## 三、要点回顾

1. 神经网络 = 线性变换 + 非线性激活的堆叠，靠**正向传播出预测、反向传播算梯度、梯度下降更新参数**三步循环训练
2. 框架（TF/PyTorch）的价值在于把反向传播和参数更新自动化——NumPy 手写一遍是理解原理的最佳方式
3. 实战中 90% 的问题出在**数据处理**（标准化、划分、泄露）而非模型结构
