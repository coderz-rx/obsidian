## 2、Agent 和大模型的区别
- 大模型：只有参数，没有记忆，无状态
- Agent：管理 LLM 的记忆

## 3、搭建一个 Agent（四层架构）
- **大脑适配层**：抹平各个大模型的 API 调用规则差异
- **双手扩展层**：实现外部工具的注册与调度。将本地 Python 函数转化为 LLM 能理解的 Schema，并在模型决定调用时，精准解析参数并执行对应代码逻辑
- **记忆管理层（Context Management）**：解决 LLM 的无状态痛点与 Token 窗口上限问题。需设计机制管理长短记忆，比如会话滑动窗口截断、历史记录摘要或向量化存储
- **中枢编排层（Control Flow）**：负责整个运行生命周期的调度。能够构建线性的处理流水线（Pipeline），或支持复杂逻辑跳转、错误重试的循环控制（Loop/DAG）

## 4、CoT（Chain of Thought）思维链
一步一步地推导，使用 "Let's think step by step" 等提示语引导模型生成中间推理过程，将复杂问题拆解为逻辑关联的子步骤，最终整合形成完整解题链路。

## 5、LangChain 的 LCEL 核心工程价值
LCEL（LangChain Expression Language，链式表达式语言）解决的最大工程痛点是**并发问题**——直接封装了并发，无需手动编码或写胶水代码，通过一个 chain 结构自动实现并发（能并发就自动并发），减少了 IO 问题、并发问题的处理，大大提高了使用效率、降低了编码复杂度。

## 6、向量相似度 vs 大模型推理
- **向量相似度**：做的是向量夹角运算，本质是空间"语义"相似度计算，属于近似计算、模糊查询，精度不高但计算快
- **大模型推理**：是推理，具有针对性，一次针对一个 prompt 进行回答，精度更高但速度慢
