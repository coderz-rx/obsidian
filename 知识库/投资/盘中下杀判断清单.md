# 盘中下杀判断清单

> 建立时间：2026-11-04
> 用途：盘中遇到突然下杀 + 资金快速流出时，快速分清「该扛」还是「该走」，以及「客观信号」还是「恐慌情绪」。
> 配套：`大盘企稳信号清单.md`（判断企稳）、`见顶信号清单.md`（判断见顶）、`交易纠错案例库.md`（历史纠错）。

---

## 一、核心认知（先记住这条）

**「跌」和「资金流出」本身，永远不构成卖出信号。**

- 资金流出是「结果」，不是「原因」。昨天 -571 亿流出是恐慌的结果，今天 +100 亿流入是乐观的结果。跟着资金流操作 = 追着别人情绪跑 = 追涨杀跌。
- 真正的卖出信号只有一个：**你买入时定的「假设」是否被证伪**（短线=止损位/趋势破位；长线=逻辑证伪）。

---

## 二、盘中下杀「五问」（判断下杀性质）

| # | 问题 | 判断 |
|---|---|---|
| ① | **来源是谁？** | 外盘共振（韩/港/美期一起跌）→ 情绪传导，A股逻辑没坏，多为跟跌；A股独跌 → 内生利空，真危险 |
| ② | **量能缩还是放？** | 缩量下杀 → 抛压衰竭，洗盘/情绪宣泄；放量下杀 → 恐慌出逃，更危险 |
| ③ | **资金结构谁在跑？** | 主力（超大+大单）跑、散户（小单）接 → 主力出货危险；主力流出放缓 → 情绪杀非趋势出货 |
| ④ | **关键位守不守？** | 5日线/20日线/前低；**5日线是收盘判断，盘中跌破不算数** |
| ⑤ | **你的票跟跌(β)还是独立跌(α)？** | 跟跌 → 逻辑没坏别慌；独立暴跌 → 查自己逻辑是否出问题 |

---

## 三、恐慌时刻卖出「三问自检」（区分情绪 vs 客观信号）

### 关键方法：区分情绪和客观信号，靠「事前写死」，不靠「盘中冷静」

恐慌会让你把「害怕」包装成「我看到破位信号了」。所以判断标准只有一个：

> **客观信号 = 可量化 + 事前定义 + 与情绪无关。**
> 杀手锏自检：**「这个卖出理由，是我买的时候 / 昨天盘前就写好的，还是现在才想出来的？」**
> - 事前写好的 → 客观信号，执行
> - 现在才想出来的 → 情绪，先别动

### 三问

1. **这笔钱是什么性质？** 短线仓→止损位/趋势破位；长线仓→逻辑证伪（业绩暴雷/订单没了/技术被颠覆）。
2. **止损位 / 证伪点到了吗？** 到了=纪律（卖在最低点也是对的）；没到只是"看着吓人"=情绪。
3. **是它自己坏（α）还是大盘带崩（β）？** 系统性杀跌是最容易错杀、最不该恐慌割的时刻。

**三个都指向"信号"，才动手；否则持有观察，让「缩量止跌 / 不再创新低」这种后续客观信号告诉你答案。**

---

## 四、一句话锚点

- 大盘下杀改变的是「短期 β」，不改变「你的长线逻辑」。
- 长线仓卖出理由只有一条：**逻辑证伪**，不是"今天大盘跌了、资金流出了"。
- 你要盯的不是"大盘跌不跌"，而是"**你的票逻辑坏没坏**"。大盘跌只是背景噪音。
