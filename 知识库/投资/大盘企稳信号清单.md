# 大盘企稳信号清单

> 建立时间：2026-11-04
> 用途：下降趋势中判断「大盘何时企稳/转势」，每天收盘对照自查当前卡在哪一级。
> 核心认知：**企稳 ≠ 反弹**。反弹是一日游，企稳是下降趋势结束、进入震荡或上升的确认。

---

## 一、三级递进信号

### A 级 —— 止跌信号（跌不动了）

| # | 信号 | 标准 |
|---|---|---|
| A1 | 不再创新低 | 出现「更高的低点」，连续 2-3 天不破前低 |
| A2 | 恐慌盘出清 | 跌停家数从几十家骤减到个位数，成交额萎缩到地量 |
| A3 | 探底回升 | 大跌日收长下影线 / 缩量十字星，下方有承接 |

### B 级 —— 企稳信号（确认止跌，进入震荡）

| # | 信号 | 标准 |
|---|---|---|
| B1 | 站回 MA5 | 指数站回 MA5 且 MA5 走平或拐头向上（不是单纯站上） |
| B2 | 主力连续净流入 | 连续 2-3 天，单日流入不算 |
| B3 | 两融止跌 | 杠杆资金不再净流出，去杠杆结束 |
| B4 | 缩量回踩不破前低 | 反弹后回踩，量能萎缩、不破位 |

> **B 级 = 可以开始试探性低吸的确认点。**

### C 级 —— 转势信号（真正拐点，可放开做）

| # | 信号 | 标准 |
|---|---|---|
| C1 | 站上 MA20 | 均线开始多头排列 |
| C2 | 持续性主线 | 某板块**连续 3 天以上领涨**，有龙头、赚钱效应扩散 |
| C3 | 赚钱效应回归 | 涨停家数持续 > 跌停家数，连板高度打开 |
| C4 | 主力 + 两融双转正 | 资金面与杠杆面同步回升 |

---

## 二、当前阶段判断（2026-11-04）

- **连 A 级都没完全满足**：11-03 还在创新低、还在跌。
- 主力 10 天净流出 2786 亿（持续失血）、两融从峰值回落 23%（去杠杆中）→ **B/C 级信号一个都没有**。
- 板块一日游 = 没有增量资金接力 = **C2「持续性主线」未出现**，所以追高是死路。

---

## 三、下降趋势中的低吸纪律（只低吸，一点高都不追）

| 原则 | 具体做法 |
|---|---|
| 只在缩量回踩时接 | 放量上涨不碰，等涨完回踩、缩量了再低吸 |
| 买在支撑位 | 前低、重要均线、缺口附近，不是「今天跌了就买」 |
| 叠加企稳信号 | 十字星 / 下影线 / 缩量，任意一个出现才考虑，绝不追红盘 |
| 分批 + 严格止损 | 低吸也可能继续跌，破位 -3% 无条件走，不补仓摊平 |

---

## 四、一句话操作锚点

- **A 级凑齐前**：只低吸、不追高、小仓位、快进快出。
- **B 级（主力连续流入 + 站回 MA5 + 两融止跌）三个都出现**：再谈加仓。
- **C 级（持续性主线 + 站上 MA20）出现**：才放开手脚。
