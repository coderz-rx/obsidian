# 交易执行准则

> 本准则综合《交易复盘（规则篇）》与《2026-07 交易复盘》整理，用于指导实际操作。指标类空白处由使用者根据自身风险偏好和交易风格填写。

---

## 一、核心原则

1. **价值探路，技术辅助**
   - 价值分析：确定股票合理估值，作为交易评估指标和泡沫判断依据。
   - 技术分析：决定具体买卖点，跟踪资金流向、筹码分布、均线等信号。

2. **不做无脑长线，以短期/波段交易为主**
   - 随着估值动态变化，动态关注和操作。
   - 大行情可以拿住，但必须有明确的技术/逻辑持有条件。

3. **风险控制优先**
   - 不躲过大跌，抄底就无从谈起。
   - 硬扛可以赢很多次，但输一次可能万劫不复。
   - 上限交给运气，下限交给纪律。

4. **买入机会，卖出风险**
   - 怕卖飞不是忽视风险的理由。
   - 怕踏空不是买入的理由。
   - 机会一直有，不要什么钱都想赚。

---

## 二、买入条件

### 2.1 市场环境（必须满足）

- [ ] 市场整体情绪、逻辑、资金面向好
- [ ] 主线明确
- [ ] 位置不高：估值未显著偏离产业领先者的估值中枢
- [ ] 资金持续净流入，底部筹码集中，有突破趋势

> 如果判断市场即将走弱，或当前处于行情后期，**不要买股**。

### 2.2 标的条件（必须满足）

- [ ] 有能让人坚持下去的逻辑闭环
- [ ] 成功率高，没有大的把握不出手
- [ ] 不是左侧交易，找临期近的、确定性高的机会
- [ ] 前期涨幅不过高，热点热度未明显下降
- [ ] 如果买高位股，必须确认当前市场风偏高、情绪好，并设置好止损位
- [ ] 如有可知的未来事件，可考虑与当下热点结合

### 2.3 买入动作

- [ ] 定好收入预期和亏损预期
- [ ] 买入要慎重
- [ ] 小资金不平铺：每次出手每个方向最多买一只股票，同时最多关注两个方向
- [ ] 仓位控制：行情好（位置不高）且主线明确时，早点下仓位；不敢重仓个股时，可踏实重仓行业指数

## 三、持仓纪律

### 3.1 可以拿住的条件

- [ ] 情绪、逻辑、资金面向好
- [ ] 判断为大行情
- [ ] 股价不破 **【待填空：5日线 / 10日线 / 其他均线】**

> "拿住"不是死扛不卖，而是上行区间不因短期波动提前下车。到达目标收益、估值泡沫或技术信号触发时，按纪律退出。

### 3.2 主动卖出条件

- [ ] 到达预定收益目标：短线【待填空】%，波段【待填空】%
- [ ] 估值进入泡沫区间：超过产业领先者估值中枢【待填空】%
- [ ] 相关热点热度明显下降
- [ ] 前期涨幅过高，性价比已低

## 四、卖出/止损条件

### 4.1 技术信号触发（必须执行）

- [ ] **高位股当日破五日线不收回，收盘卖**
- [ ] 突发事件且与持股逻辑无关，破五日线 **【待填空：半小时 / 一小时 / 收盘】** 不收回再卖
- [ ] 主力资金大幅度流出，至少不能再加仓，并考虑减仓/离场
- [ ] 总体交易一直有赚，突然变得不赚甚至亏钱，停止买票，卖出缓一缓

### 4.2 情境触发（必须执行）

- [ ] 感觉整个市场即将走弱
- [ ] 行情不好，绝不赌反转或反弹
- [ ] 大跌信号出现，不抱有"国家队会来救场"的幻想
- [ ] 出现"高位都没卖，低位更不能卖"的散户思维时，反而要强制卖出
- [ ] 跌了死拿、涨了不舍得卖又高看一眼时，立即纠正

### 4.3 止损纪律

- [ ] 单笔亏损达到 **【待填空】%** 必须离场
- [ ] 买入逻辑被证伪，立即卖出，不要等回本
- [ ] 错了就是错了，不找借口

## 五、心态与纪律

1. **定好的预期是什么，到了就卖**。认知外的钱，不要想着去赚。
2. **股市赚钱不在于一次赚多少，持续小赚也会积累成高额收益**，切忌眼高手低。
3. **要有耐心**，没有大的把握不要出手。一年只需要赚几次，把握好全年仅有的几次行情好的机会，几次就够。
4. **要信早信，不然就一直别信**。早信要建立在充分调查的基础上（消息面、市场热度、市场氛围、股票基本面等），确认后果断买入。
5. **前后一致，知行合一**。对了到达预期也要卖，错了更要卖。
6. **卖出要果断，买入要慎重**。

## 七、复盘检查清单

每次交易后对照以下问题复盘：

1. 买入时是否满足市场环境条件？
2. 买入时是否定好了收入预期和亏损预期？
3. 买入是左侧还是右侧？是否规避了左侧？
4. 持仓期间是否跟踪了均线、资金流向、热点热度？
5. 卖出是按纪律执行，还是受情绪影响？
6. 是否提前下仓位，还是前期小赚后期才加？
7. 是否出现了"散户思维"（低位不卖、等国家队救场）？
8. 下次同类行情，哪些信号可以更早识别？
